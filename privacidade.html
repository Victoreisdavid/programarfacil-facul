Política de Privacidade

Bem-vindo(a) à nossa Política de Privacidade. Na ProgramarFácil, sua privacidade e seus dados pessoais são muito importantes para nós.

1. Dados que coletamos

Podemos coletar os seguintes tipos de dados pessoais:

  • Dados fornecidos por você: nome, e-mail, telefone, dados de cadastro.
  • Dados coletados automaticamente: endereço IP, tipo de navegador, sistema operacional, páginas visitadas.
  • Dados opcionais: informações de pagamento (se houver), preferências de comunicação.

2. Como usamos seus dados

Usamos seus dados para:

  • Permitir que você use nossos cursos e conteúdos.
  • Personalizar sua experiência.
  • Enviar e-mails com novidades ou atualizações (se você autorizar).
  • Melhorar o site por meio de análises de uso.
  • Garantir a segurança da plataforma.
  • Cumprir obrigações legais.

3. Bases legais (LGPD)

Tratamos seus dados com base nas seguintes bases legais:

  • Consentimento: quando você autoriza o envio de comunicações.
  • Execução de contrato: para fornecer cursos ou serviços que você contratou.
  • Obrigação legal: para atender exigências legais.
  • Legítimo interesse: para segurança da plataforma e análise de uso.

4. Compartilhamento de dados

Seus dados podem ser compartilhados com:

  • Prestadores de serviço (hospedagem, ferramentas de e-mail, analytics).
  • Terceiros legais, quando exigido por lei.
  • Parceiros de pagamento, se você fizer transações.

5. Cookies e rastreamento

Utilizamos cookies e tecnologias semelhantes para:

  • Entender como você usa o site.
  • Manter funcionalidades essenciais (como login).
  • Oferecer uma experiência personalizada.

Você pode configurar seu navegador para aceitar ou recusar cookies.

6. Segurança dos dados

Adotamos medidas técnicas e administrativas para proteger seus dados. No entanto, nenhum sistema é completamente seguro.

7. Retenção de dados

Guardamos seus dados pelo tempo necessário para os propósitos descritos ou para cumprir exigências legais. Dados que não são mais úteis podem ser anonimizados.

8. Seus direitos (LGPD)

Você tem os seguintes direitos:

  • Acesso: saber quais dados temos sobre você.
  • Retificação: corrigir dados incorretos.
  • Eliminação: pedir a exclusão dos seus dados (quando aplicável).
  • Oposição: contestar algumas formas de uso dos seus dados.
  • Portabilidade: receber seus dados em formato estruturado.
  • Revogação de consentimento: retirar seu consentimento a qualquer momento.

Para exercer seus direitos, entre em contato conosco pelo e-mail: contato@programarfacil.com.

9. Alterações nesta política

Podemos atualizar esta Política de Privacidade. Quando fizermos mudanças importantes, notificaremos você no site ou por e-mail. A data da última atualização é exibida abaixo.

10. Contato

Se tiver dúvidas sobre esta política ou sobre seus dados, entre em contato conosco:

E-mail: contato@programarfacil.com
